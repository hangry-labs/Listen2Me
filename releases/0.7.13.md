# Listen2Me 0.7.13 — beta build

An early-access build before version 1.0.0. Features and interfaces may change.
This is not the official 1.0 release.

Windows x64. This build is self-signed. Windows may display a publisher trust warning.

What's new:

- Added an optional Start with Windows setting that launches Listen2Me in the system tray when you sign in.
- Windows startup remains separate from enabling dictation and does not open the microphone.
- Enabled shortcuts recover after locking or resuming Windows, while manual pauses and cancelled recordings remain respected.
- Added default-on hesitation-sound cleanup with a Settings switch to preserve the original wording when preferred.

Download an installer from the assets below. Checksums, licence, privacy notice
and third-party notices are included. Existing settings and models are preserved
during normal updates. Listen2Me is provided free of charge and as is.
