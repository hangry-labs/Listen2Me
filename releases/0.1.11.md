# Listen2Me 0.1.11 — early access

Speak your mind. Right where you are.

This is the first public Listen2Me build. It is free, proprietary Windows x64 software, provided as is. It is published on the stable update channel so existing installations can discover it; the app is still early access.

## Included

- Hold-to-talk, toggle and hands-free dictation into your selected text field.
- Local Parakeet, Moonshine, Nemotron and Whisper models, or your own compatible hosted ASR endpoint.
- Live preview and optional buffered live typing on compatible models.
- Bright teal-rim Windows icon and the original animated voice artwork in the app.
- Support tab with the Hangry Labs mission, software collection and optional feedback form.
- Manual update discovery, installer download progress, checksum/pinned-publisher/version verification, and explicit Install & restart.
- Update/repair and Fresh settings installer choices. Existing models and external token files are kept; a settings reset retains recoverable backups.
- Fixed installer initialization and added an actual startup-only wizard check.
- Feedback validation rejects malformed Unicode, control characters, display-name addresses and header-injection attempts before network submission.

## Privacy and availability

Local recognition runs on your computer. Hosted recognition sends audio to the endpoint you choose. There are no publisher analytics, scheduled update checks, or automatic uploads of dictation. Feedback sends only the message/type, optional reply email and version/platform; the website also sees ordinary connection metadata.

The feedback receiving endpoint is not yet deployed. Until it is available, the app reports the failed submission and keeps the message in the form; it does not claim delivery or retry automatically. Contact support@hangrylabs.app for help meanwhile.

Speech recognition and typing can be imperfect. Keep your destination selected, review inserted text, and use Your words to recover a transcript. Cancelling cannot remove text already inserted or recall audio already sent to a hosted endpoint.

## Install and update

Download Listen2Me-Setup.exe. Requires Windows 10 1809 or newer / Windows 11 x64 and Microsoft WebView2 Runtime. Windows on ARM and other desktop platforms have not been qualified.

This release is **self-signed**, not signed by a publicly trusted publisher. Windows or SmartScreen may show an unknown-publisher warning. Checksums and the public publisher certificate are included for verification; do not install the certificate as a trusted root. Signing and antivirus checks do not guarantee safety.

Installed 0.1.10 users can choose Settings → Application updates → Check for updates, then Download update and Install & restart. No update is installed automatically. Older builds before 0.1.9 require one manual tray Quit.

The licence, privacy notice and third-party notices are included as release assets and in the installer. Third-party components/models retain their own licences. No support response time or future updates are promised.

Built with Go 1.26.10, including current Go 1.26 security fixes. Source and packaged-binary Go vulnerability checks are part of release preparation; these checks do not cover every downloaded native model runtime.
