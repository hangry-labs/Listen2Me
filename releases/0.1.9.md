# Listen2Me 0.1.9 preview

- Bright teal-rim desktop icon, preserving the original animated in-app artwork.
- Support tab with the Hangry Labs mission and software links.
- Optional in-app feedback form, pending the website receiving endpoint. Email is optional; nothing is sent automatically.
- Manual stable-release checking, verified installer downloads with progress, and an explicit Install & restart action. No stable public feed has been published yet.
- Installer update/repair detection, downgrade prevention and optional fresh settings with timestamped backups. Downloaded models and external token files are preserved.
- Older installed builds need one manual tray Quit before their first maintenance-aware update.

This preview is self-signed. Windows/SmartScreen may show an unknown-publisher warning; do not install the public certificate as a trusted root.
