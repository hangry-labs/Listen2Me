# Listen2Me 0.1.10 preview

Fix installer startup when an existing Listen2Me installation is detected. Read its registered path without expanding the application-directory constant before Inno Setup initializes it. A startup-only diagnostic verifies all wizard pages before exiting without installation or app shutdown.

Includes the manual updater, update/repair and fresh-settings modes, and the optional feedback form introduced in 0.1.9. The feedback API and stable public update feed still require deployment/publication. Models and external token files are preserved during maintenance.

This preview is self-signed; Windows may show an unknown-publisher warning. Do not install the public certificate as a trusted root.
