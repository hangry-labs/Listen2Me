# Listen2Me 0.1.8 — preview

Initial public distribution candidate. This release is self-signed; Windows may
show a publisher trust warning. The public certificate and SHA256SUMS are provided
for verification, not for installing a trusted Windows root certificate.

- Go/Wails Windows hold-to-talk and hands-free dictation with optional live typing.
- Hosted ASR or explicit local model downloads with CPU/validated NVIDIA CUDA.
- Parakeet recommended for completed takes; Moonshine Medium/Small for English
  streaming, with bounded ONNX threading. Nemotron remains multilingual.
- About, contact addresses, offline software licence and privacy notice in the app.
- Installer and public texts share the same licence/privacy sources.
- Concise proprietary freeware licence with a conventional as-is disclaimer.
- Explicit modification/derivative-work restrictions and termination on breach.

Recognition, punctuation and target-editor behavior vary. Review text before
sending. App updates are currently manual; automatic update checks are not yet
implemented. Close Listen2Me from its tray before running the installer. Existing
settings and model downloads are retained.
