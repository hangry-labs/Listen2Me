# Reporting a vulnerability

Send private vulnerability reports to [security@hangrylabs.app](mailto:security@hangrylabs.app).
Include the Listen2Me version, affected feature and a minimal description or safe
reproduction. Do not include real credentials or other people's private speech.
Please do not disclose vulnerabilities in public issues before coordination.

Use the latest available release and check its notes for known limitations.
There is no promised response time, paid support plan or bug-bounty programme.
For ordinary help use [support@hangrylabs.app](mailto:support@hangrylabs.app).
